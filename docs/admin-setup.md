# راه‌اندازی پنل مدیریت ناب استور

## تنظیم ایمیل مدیر

در تنظیمات محیط اجرای Cloudflare Worker یک متغیر متنی با نام `ADMIN_EMAIL` تعریف کنید و ایمیل یگانه مدیر را در آن قرار دهید. این مقدار باید دقیقاً با ایمیل کاربر Supabase Auth مطابقت داشته باشد.

متغیرهای سمت سرور موردنیاز:
- `ADMIN_EMAIL`
- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY`

کلید service role فقط باید به‌عنوان secret سمت سرور ذخیره شود و هرگز در متغیرهای `VITE_*`، کد مرورگر یا مخزن Git قرار نگیرد.

## ساخت حساب مدیر

در Supabase به بخش Authentication > Users بروید و یک کاربر با ایمیل تعریف‌شده در `ADMIN_EMAIL` و رمز عبور قوی بسازید. ورود سایر حساب‌ها در پنل پذیرفته نمی‌شود؛ مجوز دسترسی در هر درخواست سمت سرور با اعتبارسنجی JWT و تطبیق ایمیل بررسی می‌شود.

## اعمال Migration

فایل‌های SQL این پوشه را به ترتیب زمانی در Supabase SQL Editor اجرا کنید:
1. `20261118000000_atomic_order_rate_limit.sql`
2. `20261118010000_lock_orders_to_server.sql`

Migration دوم دسترسی نقش‌های مرورگر `anon` و `authenticated` را از جدول سفارش‌ها می‌گیرد. خواندن و تغییر وضعیت سفارش‌ها فقط از تابع‌های سمت سرور و پس از تأیید حساب مدیر انجام می‌شود.

## استفاده

پس از انتشار نسخه جدید، مسیر `/admin` را باز کنید. پنل حداکثر ۱۰۰ سفارش آخر را نمایش می‌دهد و فقط وضعیت سفارش قابل تغییر است.
