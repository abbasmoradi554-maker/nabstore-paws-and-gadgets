# راه‌اندازی پنل مدیریت ناب استور

این راهنما مربوط به نسخه آزمایشی (Preview) ناب استور است. پیش از هر تغییری، مطمئن شوید پروژه انتخاب‌شده همان پروژه Preview با شناسه `ckprslldievdducraeyu` است. تنظیمات Production را از این راهنما تغییر ندهید.

## پیش‌نیازهای محیط اجرا

نسخه فعلی از Supabase Auth و کلید عمومی Publishable استفاده می‌کند. متغیرهای عمومی موردنیاز برای build:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

**کلید Service Role لازم نیست** و نباید در کد مرورگر، متغیرهای `VITE_*` یا مخزن Git قرار داده شود. در نسخه فعلی، دسترسی مدیر با JWT حساب واردشده، تطبیق ایمیل مدیر و سیاست‌های RLS دیتابیس کنترل می‌شود.

ایمیل مدیر در کد توابع مدیریتی فعلی به‌صورت ثابت تنظیم شده است:

`abbasmoradi554@gmail.com`

اگر ایمیل مدیر قرار است عوض شود، تمام محل‌های بررسی ایمیل مدیر و سیاست‌های RLS باید با هم بازبینی و هماهنگ شوند؛ صرفاً تغییر یک متغیر محیطی کافی نیست.

## ساخت حساب مدیر

1. وارد داشبورد پروژه Preview در Supabase شوید.
2. به بخش **Authentication → Users** بروید.
3. حساب مدیر را با ایمیل بالا ایجاد کنید.
4. رمز عبور قوی و منحصربه‌فرد تعیین کنید و آن را فقط در Password Manager خود نگه دارید.
5. با همان حساب در مسیر `/admin` نسخه Preview وارد شوید.

رمز عبور را در کد، مخزن Git، پیام یا تنظیمات عمومی Cloudflare قرار ندهید.

## مسیرهای پنل

- `/admin`: پنل یکپارچه مدیریت سفارش‌ها، محصولات و محتوای فروشگاه
- `/admin?tab=products`: تب مدیریت محصولات
- `/admin?tab=content`: تب تنظیمات و محتوای فروشگاه
- `/admin/products`: مسیر سازگاری قدیمی که به تب محصولات در پنل یکپارچه هدایت می‌شود.

## دیتابیس و Migrationها

ساختار و سیاست‌های دسترسی پروژه Preview قبلاً برای محصولات، سفارش‌ها، محتوای فروشگاه و بارگذاری تصاویر اعمال شده‌اند. Migrationها را دوباره و دستی اجرا نکنید؛ اجرای تکراری یا خارج از ترتیب می‌تواند باعث خطا یا تغییر ناخواسته شود. پیش از هر Migration جدید، وضعیت واقعی جدول‌ها و سیاست‌های RLS را بررسی کنید.

- خواندن عمومی محصولات فقط برای محصولات فعال مجاز است.
- ایجاد سفارش از مسیر امن ثبت سفارش انجام می‌شود.
- خواندن و تغییر وضعیت سفارش‌ها و مدیریت محصولات به هویت مدیر و سیاست‌های دسترسی محدود است.
- تصاویر محصولات در Storage عمومی نمایش داده می‌شوند، اما بارگذاری آن‌ها باید با نشست مدیر مجاز انجام شود.

## تنظیم امنیت Auth

در داشبورد Supabase پروژه Preview، بخش **Authentication → Settings / Password Security** را باز کنید و قابلیت **Leaked Password Protection** را فعال کنید. این گزینه از پذیرش رمزهایی که در نشت‌های شناخته‌شده دیده شده‌اند جلوگیری می‌کند. ابزار متصل فعلی نتوانست این تنظیم را تغییر دهد؛ فعال‌سازی آن باید از داشبورد انجام و سپس دوباره بررسی شود.

## قبل از استفاده واقعی

- ورود مدیر، خروج، بازیابی رمز، فهرست سفارش‌ها و تغییر وضعیت سفارش را در مرورگر آزمایش کنید.
- ساخت، ویرایش، غیرفعال‌سازی محصول و بارگذاری تصویر را با حساب مدیر آزمایش کنید.
- محصولات نمونه را تا زمان تأیید تأمین‌کننده، قیمت نهایی و موجودی به‌عنوان کالای قطعی آماده فروش معرفی نکنید.
- هزینه و روش ارسال را با شرایط واقعی فروشگاه هماهنگ کنید.
- درگاه پرداخت آنلاین عمداً غیرفعال است؛ تا زمان تصمیم جداگانه مدیر، پرداخت فقط با هماهنگی پشتیبانی انجام می‌شود.
- پیش از انتشار Production، تست‌های مرورگری و امنیتی را روی محیط Production به‌صورت جداگانه و با مجوز صریح انجام دهید.

این راهنما به‌روزرسانی مستندات است و به‌تنهایی هیچ تغییری در حساب مدیر، رمز عبور، درگاه پرداخت یا محیط Production ایجاد نمی‌کند.
